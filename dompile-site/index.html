01 The idea

Three files in.
One world out.

Web projects tend to scatter. Dompile brings the pieces back together, so a page is as easy to move, share, and understand as a single file.

01<>

Bring your source

Start with the HTML, CSS, and JavaScript you already have. Local styles and scripts can be pulled in automatically.

page.htmlstyles.cssapp.js
02✳

Let Dompile compile

Run one command. Dompile combines your structure, styles, and behavior into a self-contained DTML document.

$ dompile -h page.html

Ship it your way

Compile DTML as a website, or generate an Electron project when your web app needs a desktop home.
